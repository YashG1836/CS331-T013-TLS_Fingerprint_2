# Results and provenance

- `baseline/` contains the earlier team-supplied QUIC v1 TShark/FoxIO outputs.
- `summary.md` and `summary.json` are audited imports of Yash's Track 1 results. The unmodified source files are preserved under `imported/`; the audited table changes only the zero-packet IPv6 row's agreement field to not-comparable and records its packet status.
- `raw/<capture-id>.json` preserves Yash's raw analysis outputs for the 15 Track 1 PCAPs. `versions.txt` and `checkpoint_build_test.txt` are imported environment/test logs, not current-run logs.
- `preflight.json` is the original WSL snapshot. `make preflight` writes new local results to `preflight-current.json` so it cannot overwrite the imported snapshot.
- `evaluation.json` is generated by `make eval` from the current manifest. It validates evidence inventory and hashes; it does not infer a limitation or produce final statistics.
- `reproduced/` is Git-ignored. `make lab-eval` writes fresh tool versions, per-capture outputs, and a new summary there; this keeps imported data immutable. Full local C++ QUIC extractor logs (with ClientHello hex) may also be kept there. `quic-extractor-comparison.json` records local recovery counts and the user's reported 10/10 exact `tls.handshake_raw` byte-set matches, with provenance noting that raw exports/script are not yet retained in the repo.
- `track1/` explains imported capture-log and ECH page observations. The key log and raw page dumps containing workstation/network identifiers were not imported.

Regenerate only from reviewed committed evidence. Never hand-edit measured values or present imported outputs as rerun results.
