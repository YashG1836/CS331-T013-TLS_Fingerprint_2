# AI-use records

Store course-required raw, timestamped AI-use exports here, with the related implementation work. Do not fabricate, rewrite as contemporaneous logs, or include credentials, TLS key logs, or unrelated private information. Follow course privacy and disclosure rules.

`prompts.txt` is explicitly a **partial** record of the one verbatim user prompt available in the current repository session context; it lacks an exact timestamp and earlier prompts. It does not satisfy a requirement for a complete, source-exported, timestamped log. Replace/augment it only with the actual approved export; do not reconstruct missing history.
